## 1. الهيدر (Header = TopBar + Navbar)

### 📐 التخطيط
`<header className="sticky top-0 z-50">` يضم TopBar (اختياري) ثم Navbar.

### 🎨 المرئي — الشريط العلوي (TopBar)
- خلفية `#f8f9fa`، حدود سفلية `border-b border-gray-100`، ارتفاع `h-10`، نص `text-[13px] text-gray-600`.
- يمين: الهاتف `tel:` + البريد `mailto:` (أيقونات Phone/Mail سماوية 14px، النص `dir="ltr"`)؛ يسار: أيقونات سوشيال `SocialLinks size=sm` (دوائر سماوية).

### 🎨 المرئي — شريط التنقل (Navbar)
- خلفية بيضاء `h-[68px]`؛ عند التمرير >12px يكتسب `shadow-nav`.
- اللوجو (يمين): صورة `h-10` أو نص (الكلمة الأولى dark + الباقي سماوي).
- الروابط (وسط، `lg+`): `px-3 py-2 text-[15px] font-medium` بلون `#333` + خط سفلي سماوي `h-0.5` يتمدد عند hover/النشاط.
- رابط "الخدمات": سهم `ChevronDown` يدور 180° + قائمة منسدلة `min-w-[240px]` بيضاء.
- يسار: زر "اطلب عرض سعر" (`btn-primary btn-sm`) + زر اللغة (`Globe`، يظهر فقط إن `bilingual`) + زر الهامبرغر.

### 🖱️ التفاعل
- hover رابط → سماوي + خط سفلي؛ القائمة المنسدلة تظهر بـ `opacity/translate-y` خلال 200ms؛ الرابط النشط سماوي دائماً.

### 📱 المتجاوب
- **<640px:** TopBar مخفي. **<1024px:** الروابط تختفي → Drawer منزلق من اليمين بعرض 82% (بحد 384px) + طبقة `bg-black/50` + قفل تمرير الجسم + زر X + زر "اطلب عرض سعر" بعرض كامل.
- **≥1024px:** روابط أفقية.

### 🔄 الديناميكي
- الروابط من `getMenu('header')`؛ الخدمات الفرعية من آخر 8 خدمات؛ TopBar يختفي إذا `topBarEnabled=false` أو لا يوجد هاتف/بريد.

### 🧭 رحلة الاستخدام
1. يفتح الزائر الموقع → يرى TopBar + Navbar فوراً.
2. يتنقل بالروابط؛ يتابع القائمة المنسدلة للخدمات.
3. على الموبايل يضغط ☰ → تنزلق القائمة → يختار رابطاً → تُغلق القائمة تلقائياً.

## 2. الفوتر (Footer)

### 📐 التخطيط
`bg-dark`، شبكة `grid` (1 عمود → `sm:2` → `lg:4`) بفجوة `gap-10` وحشوة `py-14`.

### 🎨 المرئي
- **عمود 1:** لوجو فاتح (`brightness-0 invert`) + فقرة `text-gray-400` + سوشيال (دوائر سماوية).
- **عمود 2/3:** عنوان أبيض `font-bold text-lg` + خط سماوي `w-12 h-0.5` + روابط `text-gray-400 text-sm`.
- **عمود 4:** العنوان/الهاتف/البريد/ساعات العمل بأيقونات سماوية 16px.
- **شريط الحقوق:** `bg-darker`، نص `text-sm text-gray-400` + رابطا الخصوصية/الشروط.

### 🖱️ التفاعل
hover على الروابط → سماوي + إزاحة لليسار `-translate-x-1`.

### 📱 المتجاوب
الأعمدة تتكدس: 1 (موبايل) → 2 (تابلت) → 4 (ديسكتوب).

### 🔄 الديناميكي
كل النصوص من الإعدادات؛ الخدمات من آخر 6؛ السنة تُحسب تلقائياً.

## 3. زر واتساب العائم + العودة للأعلى

### 📐 + 🎨 + 🖱️
- **واتساب:** `fixed bottom-5` (يمين/يسار حسب الإعداد)، دائرة `w-14 h-14` خضراء `#25D366` + أيقونة بيضاء + حلقة نبض `pulseRing`؛ يظهر بعد 900ms؛ hover يكبر 110%؛ الضغط يفتح `wa.me` برسالة ترحيبية.
- **التلميح:** بطاقة بيضاء "تحتاج مساعدة؟" + زر X.
- **العودة للأعلى:** `fixed bottom-5 right-5` دائرة `w-11 h-11` سماوية بسهم أبيض؛ يظهر بعد >420px (fade+slide)؛ hover يغمق ويرتفع؛ الضغط يمرر لأعلى بنعومة.

### 🔄 الديناميكي
رقم واتساب/الرسالة/التلميح/الموضع/الإظهار من `whatsappSettings`؛ الزر يختفي إن `enabled=false` أو لا رقم.

## 12. اطلب عرض سعر (Quote)

- بانر + شبكة `lg:grid-cols-[1fr_300px]`؛ النموذج في `card p-6/9`؛ عمود جانبي بثلاث بطاقات (رد 48 ساعة/استشارة مجانية/سرية).
- **النموذج (`QuoteForm`):** شبكة `sm:grid-cols-2`؛ الاسم/الشركة/البريد/الهاتف/نوع المشروع (خدمات)/الميزانية/الجدول الزمني/وصف المشروع (textarea)/ملفات مرفقة (سحب/إفلات `border-2 border-dashed` تعرض الامتدادات والحجم الأقصى + قائمة ملفات قابلة للحذف، حد 5 ملفات)؛ زر "إرسال الطلب" بعرض كامل.

### 🧭 رحلة (بكل الحالات)
- حقول إلزامية فارغة → Toast تحذير برتقالي + `ring` على الحقول.
- ملف غير مسموح/أكبر من الحد → Toast تحذير + يستمر مع تجاهل الملف.
- إرسال → Spinner + تعطيل → **نجاح:** شاشة نجاح كاملة (أيقونة خضراء + "تم إرسال طلبك" + "إرسال طلب آخر") + تمرير لأعلى → **خطأ:** Toast أحمر + بقاء البيانات.

## 13. الأسئلة الشائعة (FAQ)

- بانر + `jsonLd FAQPage` + تبويبات تصنيفات + `Accordion`.
- **Accordion:** المفتوح `border-primary/40 bg-primary/[.04]` بنص سماوي وسهم للأعلى؛ الانزلاق عبر `grid-rows-[0fr→1fr]`؛ أول سؤال مفتوح افتراضياً.

---

## 14. الخصوصية + الشروط (LegalPage)

- بانر + شبكة `lg:grid-cols-[260px_1fr]`؛ **جدول محتويات** (sticky) يتبع التمرير ويميّز القسم النشط بخط سماوي جانبي (يُبنى تلقائياً من H2/H3)؛ المقال يعرض "آخر تحديث" ثم المحتوى الغني.
- **📱:** جدول المحتويات مخفي تحت `lg`.

---

## 15. صفحة 404

- `min-h-[70vh]` متمركزة؛ "404" ضخم `text-[7rem]/[10rem] font-black text-primary/25` (أو صورة) + عنوان + فقرة + مربع بحث (يوجّه لـ `/blog?search=...`) + زر "العودة للرئيسية".
- **🔄:** من `pages` مفتاح `notfound`.

## 16. صفحتا الصيانة والحظر (يولّدهما الخادم خارج React)

### وضع الصيانة (503)
عند تفعيله، أي زائر غير مسجّل دخول يرى صفحة HTML مستقلة: خلفية متدرجة `#f5f7fa→#e8f7f9` + بطاقة بيضاء `border-radius:20px` + أيقونة 🛠️ (أو صورة) + عنوان + رسالة + اسم الموقع + **عدّاد تنازلي** (أيام/ساعات/دقائق/ثواني) ببطاقات سماوية يتحدث كل ثانية، وعند الانتهاء "عدنا — حدّث الصفحة".
- المسارات `/api`, `/Akramadmin`, `/uploads`, `/_next` مستثناة؛ فريق العمل المسجّل يواصل التصفح.

### الحظر (403)
IP المحظور يرى "403 — تم حظر الوصول من عنوانك" (صفحة)، أو JSON خطأ للـ APIs.
