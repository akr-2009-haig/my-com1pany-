# 🧩 الجزء 3 — مكوّنات لوحة التحكم المشتركة

| المكوّن | المواصفات |
|---|---|
| **DataTable** | `admin-card`؛ بحث (أيقونة يمين) + شريط أدوات؛ شريط تحديد جماعي سماوي؛ رأس `bg-gray-50`؛ صفوف hover `bg-primary/[.03]`، المحدد `bg-primary/5`؛ ترقيم مع اختيار 10/20/50/100 |
| **Modal** | خلفية `bg-black/50` + بطاقة `rounded-2xl` بمقاسات sm/md/lg/xl/full؛ رأس + زر إغلاق أحمر؛ فوتر `bg-gray-50`؛ إغلاق بـ Esc |
| **ConfirmModal** | `max-w-md`؛ أيقونة تحذير بدائرة (حمراء/سماوية)؛ "إلغاء" رمادي + "نعم" أحمر/سماوي |
| **ToggleSwitch** | `w-11 h-6` (sm `w-9 h-5`)؛ سماوي مفعل/رمادي معطل؛ الكرة تنزلق 20px |
| **FormBuilder** | تبويبات (النشط بحد سفلي سماوي) + شبكة `sm:grid-cols-2` |
| **Field** | نص/رقم/تاريخ/قائمة/قائمة متعددة/textarea/تبديل/أيقونة/لون/صورة/صور/نص غني/قائمة ديناميكية/وسوم + خطأ أحمر |
| **DynamicList** | صفوف متكررة (سحب + أسهم ترتيب + حذف أحمر) + زر "+ إضافة" متقطع سماوي |
| **DragList** | عناصر قابلة للسحب (HTML5)؛ المسحوب شفاف، الهدف بحدود سماوية وحلقة |
| **ImageUploader** | منطقة `border-2 border-dashed` بنسبة أبعاد؛ أزرار استبدال/حذف عند hover؛ خيار "إدخال رابط" |
| **MultiImageUploader** | شبكة `grid-cols-2/3/4`؛ أول صورة "الغلاف"؛ تقديم/تأخير/حذف؛ عداد "X / 12" |
| **RichTextEditor** | شريط أدوات كامل + `contentEditable` بنمط `prose-rtl` + وضع HTML خام |
| **IconPicker** | زر + شبكة `grid-cols-6/8` + بحث |
| **ColorPicker** | منتقي ألوان + حقل HEX + 9 ألوان مسبقة |
| **TagInput** | شارات داخل حقل؛ Enter/فاصلة للإضافة، Backspace للحذف |
| **StatsCard** | أيقونة مربعة بلون شفاف + القيمة + نسبة التغيير |
| **Guard** | شاشة تحميل أو "لا تملك صلاحية الوصول" (درع أحمر) |
| **Badge** | شارة حالة ملونة |
| **PageHeader** | Breadcrumb + عنوان `text-xl/2xl` + وصف + أزرار |
| **DetailGrid** | شبكة `sm:grid-cols-2` من صناديق `bg-gray-50` |
| **LineChart** | SVG بخط سماوي + تعبئة متدرجة + tooltip داكن |
| **PieChart** | دونات بعدّاد إجمالي مركزي + legend بنسب |
| **BarChart** | أشرطة أفقية سماوية `transition-all duration-700` |
