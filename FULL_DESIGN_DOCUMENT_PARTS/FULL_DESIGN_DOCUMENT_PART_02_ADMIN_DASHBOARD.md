## 17. صفحة تسجيل الدخول

### 📐 + 🎨
- شاشة `lg:grid-cols-2` بخلفية `adminbg`.
- **يمين (علامة تجارية):** `bg-dark` بنص أبيض + توهجات سماوية `blur-3xl` + شعار "A" في مربع `w-14 h-14 rounded-2xl bg-primary` + عنوان `text-4xl font-extrabold` + وصف + 3 نقاط بأيقونات درع + حقوق.
- **يسار (نموذج):** بطاقة بيضاء `rounded-2xl shadow-card p-7/9 max-w-md`: عنوان "تسجيل الدخول" + صندوق خطأ أحمر + حقل بريد (أيقونة Mail، `dir=ltr`) + كلمة مرور (Lock + زر عين) + "تذكرني" (checkbox سماوي) + "نسيت كلمة المرور؟" + زر "دخول" `btn-primary w-full`.
- **خطوات:** login → 2fa (حقل رمز 6 أرقام `tracking-[0.6em]`) → forgot.

### 🧭 رحلة (بكل الحالات)
1. بيانات خاطئة → صندوق أحمر + "المحاولات المتبقية: N".
2. 5 محاولات فاشلة/15 دقيقة → 429 "تم حظر عنوانك مؤقتاً لمدة 30 دقيقة" + تسجيل IP.
3. حساب معطل → "تم تعطيل هذا الحساب".
4. 2FA → رمز بريد (صالح 10 دقائق)؛ الزر يتعطل حتى 6 أرقام؛ رمز خاطئ → خطأ.
5. نسيان → رسالة نجاح خضراء "إذا كان البريد مسجلاً سيصلك رابط".
6. نجاح → تحويل لـ `/Akramadmin` (أو `?next=`).

### 📱
تحت `lg`: يظهر النموذج فقط (العلامة التجارية مخفية) مع شعار صغير أعلى.

## 20. إدارة الصفحة الرئيسية

### 20.1 السلايدر (hero) — `CrudPage`
- **جدول:** الصورة المصغرة `w-20 h-12`، العنوان، الفرعي، الترتيب، الحالة (Toggle)، الإجراءات.
- **نموذج (Modal lg) بتبويبات:** المحتوى (عنوان/فرعي/صورة/تفعيل/ترتيب)؛ الأزرار (نص+رابط الزر الأول، Toggle الزر الثاني + نصه/رابطه بشروط)؛ الإنجليزية.
- **سحب وإفلات** للترتيب + زر "معاينة الرئيسية".

### 20.2 الإحصائيات (stats) — `CrudPage`
- **جدول:** الأيقونة، الرقم (+/لاحقة)، التسمية، الترتيب، الحالة.
- **نموذج:** الرقم (number)، التسمية، الأيقونة (`IconPicker` بشبكة + بحث)، لاحقة، Toggle "إظهار +"، تسمية EN، تفعيل.

### 20.3 من نحن / لماذا تختارنا / CTA — `PageEditor`
- تعديل Singleton: Toggle "إظهار القسم" + نصوص/صورة + قائمة ديناميكية (نقاط/مزايا) + حفظ لاصق أسفل.

### 20.4 ترتيب الأقسام (sections-order)
- قائمة `DragList` (رقم تسلسلي + اسم + مفتاح + badge ظاهر/مخفي + Toggle) + لوحة ملخص (إجمالي/ظاهرة/مخفية) + "حفظ الترتيب" + شريط "لديك تغييرات غير محفوظة" برتقالي.
- ⚡ بعد الحفظ → `sections:updated` → الموقع يتحدث فوراً.
