# 🔄 الجزء 7 — دورة الحياة (من فعل الأدمن إلى ظهوره للزائر)

| ما يفعله الأدمن | ما يظهر للزائر (لحظياً) |
|---|---|
| إضافة/تعديل/إخفاء شريحة | السلايدر يتحدث فوراً |
| تفعيل/إخفاء قسم | يظهر/يختفي فوراً |
| إضافة خدمة مميزة | تظهر في الرئيسية والخدمات فوراً |
| إضافة مشروع/باقة/مقال | يظهر في موضعه فوراً |
| تغيير الترتيب | يتحدث فوراً |
| الموافقة على تعليق | يظهر في المقال فوراً |
| تغيير الإعدادات (شعار/واتساب/سوشيال) | يتحدث في كل الصفحات فوراً |
| تفعيل الصيانة | الزوار يرون 503 (عدّاد) |
| حظر IP | المحظور يرى 403 |
| تغيير الصلاحيات | المستخدم يفقد/يكتسب الأقسام عند إعادة الدخول |
